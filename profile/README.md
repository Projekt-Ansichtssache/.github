# Projekt Ansichtssache

Making the web more accessible.

Projekt Ansichtssache is a student project focused on digital accessibility. Our goal is to make the web more inclusive through simple, accessible and easy-to-use tools.

## Projects

- Accessibility Widget: [GitHub](https://github.com/Projekt-Ansichtssache/accessibility-widget)
- Accessibility Widget Preview: [Preview Website](https://projekt-ansichtssache.github.io/accessibility-widget-preview/), [GitHub](https://github.com/Projekt-Ansichtssache/accessibility-widget-preview)
- Accessibility Widget Extension: [GitHub](https://github.com/Projekt-Ansichtssache/accessibility-widget-extension), [Chrome Web Store](https://chromewebstore.google.com/detail/kffkafdmlcmmiefggbniofjmlkoiplkm?utm_source=item-share-cb), [Firefox Browser Add-Ons](https://addons.mozilla.org/de/firefox/addon/accessibility-widget-by-p-a/)
- Projekt Ansichtssache Website: [Website](https://projekt-ansichtssache.github.io), [GitHub](https://github.com/Projekt-Ansichtssache/Projekt-Ansichtssache.github.io)
