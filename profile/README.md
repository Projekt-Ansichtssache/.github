# Projekt Ansichtssache

Making the web more accessible.

Projekt Ansichtssache is a student project focused on digital accessibility. Our goal is to make the web more inclusive through simple, accessible and easy-to-use tools.

## Projects

- [Accessibility Widget](https://github.com/Projekt-Ansichtssache/accessibility-widget) – A customizable accessibility widget for websites.

## Development

Developed by students of Gymnasium Oesede.

Source code is available on GitHub.
